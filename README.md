#### Voice Integrity Engine (Real-Time Deepfake Detection)
_PyTorch, WavLM, LFCC-LCNN, FastAPI_

- Ensembled spectral and transformer logits via Platt scaling and EMA smoothing to achieve **91.5% zero-day recall** at 1.7% false alarm rate.
- Deployed a sub-250ms streaming FastAPI WebSocket pipeline with RMS VAD.

#### ExoTerra (NASA Exoplanet Characterization Engine)
_Python, Scikit-Learn, NASA TAP API, Streamlit_
- Ingested and cached 5,800+ confirmed exoplanets utilizing NASA’s TAP API.
- Modeled Stefan-Boltzmann flux and Kopparapu Habitable Zone boundaries.
