<h2 align="center"> 🚀 Featured Projects </h2>

### 🎙️ Voice Integrity — Real-Time Deepfake Voice Detection Engine
> **Tech:** PyTorch, WavLM, LFCC-LCNN, FastAPI

Open-sourced anti-spoofing models on Hugging Face (LFCC-LCNN & WavLM Base+), engineering a 7,000 Hz low-pass parity gate to eliminate resampler spectral bias. Ensembled spectral and transformer logits via Platt scaling and EMA smoothing, achieving 91.5% zero-day recall at 1.7% false alarm rate across 25 unseen generators; built sub-250 ms streaming FastAPI WebSocket pipeline with RMS VAD.

### 🪐 ExoTerra — NASA Exoplanet Characterization & Discovery Engine
> **Tech:** Python, Scikit-Learn, NASA TAP API, Streamlit

Ingested and cached 5,800+ confirmed exoplanets via NASA’s TAP API with Chen & Kipping empirical mass-radius relations and Stefan-Boltzmann flux modeling; implemented Kopparapu Habitable Zone polynomial boundaries and Earth Similarity Index (ESI). Deployed an unsupervised ML suite including Silhouette-optimized K-Means, GMM boundary transition entropy, 3D PCA capturing 89.2% cosmological variance, and Isolation Forest detecting extreme celestial anomalies.

### 🏭 Air Quality Forecasting & Source Attribution Engine
> **Tech:** Python, XGBoost, Prophet, FastAPI, OpenAQ, Groq

Engineered an autoregressive 24-hour AQI forecasting pipeline using recursive XGBoost on 3-year OpenAQ data, benchmarked against Prophet and persistence baselines. Developed a heuristic attribution engine computing emission breakdown (Traffic, Industry, Construction) using PM10/PM2.5 ratios, chemical markers (NO2, SO2), and wind vectors with dynamic station retraining endpoints in FastAPI.
