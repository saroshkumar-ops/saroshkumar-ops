## 🌌 Engineering Portfolio

### 🎙️ Voice Integrity Engine (Real-Time Deepfake Detection)
<kbd>PyTorch</kbd> <kbd>WavLM</kbd> <kbd>LFCC-LCNN</kbd> <kbd>FastAPI</kbd>
> Engineered a **7,000 Hz low-pass parity gate** to eliminate resampler spectral bias. Ensembled spectral and transformer logits via Platt scaling and EMA smoothing to achieve **91.5% zero-day recall** at a 1.7% false alarm rate across 25 unseen generators. Built a **sub-250ms** streaming FastAPI WebSocket pipeline with RMS VAD.

### 🪐 ExoTerra (NASA Exoplanet Characterization Engine)
<kbd>Python</kbd> <kbd>Scikit-Learn</kbd> <kbd>NASA TAP API</kbd> <kbd>Streamlit</kbd>
> Ingested and cached **5,800+ confirmed exoplanets** utilizing NASA’s TAP API. Modeled Stefan-Boltzmann flux and Kopparapu Habitable Zone boundaries. Deployed unsupervised ML (Silhouette-optimized K-Means, Isolation Forest) to map extreme celestial anomalies and calculate Earth Similarity Index (ESI).

### 🏭 AQI Forecasting & Attribution Engine
<kbd>XGBoost</kbd> <kbd>Prophet</kbd> <kbd>FastAPI</kbd> <kbd>OpenAQ</kbd>
> Built an autoregressive **24-hour AQI forecaster** with recursive XGBoost on 3-year OpenAQ data. Developed a heuristic attribution engine to dynamically break down emissions (Traffic, Industry, Construction) using PM10/PM2.5 ratios and chemical markers via dynamic station retraining endpoints in FastAPI.
